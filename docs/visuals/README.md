# Material visual del portfolio

## Principio

Las imágenes del portfolio son evidencia. No son decoración.

Por eso seguimos este orden:

1. identificar qué queremos demostrar;
2. revisar qué información real puede utilizarse;
3. recrear con datos ficticios cuando exista riesgo de privacidad;
4. revisar que la recreación no invente capacidades o resultados;
5. aprobar la pieza;
6. incorporarla a la web.

## Estados

Cada pieza puede estar en uno de estos estados:

- **Exploración**: sirve para probar una idea visual. No se publica.
- **Candidata**: el concepto funciona, pero falta revisar contenido, exactitud o privacidad.
- **Aprobada**: puede incorporarse a la web pública.

## Regla sobre métricas

No se publican porcentajes de mejora, ahorro de tiempo, reducción de errores u otras métricas de impacto salvo que podamos explicar de dónde salen y sean seguras para publicación.

Cuando no exista una medición fiable, es preferible describir el resultado de forma cualitativa antes que fabricar una cifra.

## Regla sobre recreaciones

Una recreación puede simplificar una interfaz para explicar mejor una idea, pero no puede presentar como existente una funcionalidad que no forme parte del trabajo realizado.

Cuando sea necesario, la página indicará que se trata de una recreación con datos ficticios.
