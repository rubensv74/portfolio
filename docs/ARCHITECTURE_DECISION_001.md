# Decisión de arquitectura 001 — Astro + GitHub Pages

## Estado

Aprobada.

## Decisión

La primera versión del portfolio se construirá con **Astro** y se publicará mediante **GitHub Pages**.

## Motivo

El portfolio será principalmente una web de contenido: perfil profesional, casos de estudio, proyectos y, más adelante, artículos. La prioridad no es construir una aplicación compleja, sino mantener una web rápida, clara, fácil de actualizar y preparada para crecer.

Astro encaja bien porque permite separar el contenido del diseño y trabajar con páginas ligeras. GitHub Pages permite publicar la web sin coste y mantener todo el proceso unido al repositorio.

## Principios que quedan fijados

1. El contenido profesional estará separado de la presentación visual.
2. Los proyectos se tratarán como casos de estudio reutilizables.
3. La web deberá funcionar como sitio estático y rápido.
4. La publicación será automática desde GitHub cuando la V1 esté lista.
5. La privacidad tendrá prioridad sobre mostrar detalles técnicos.
6. La primera versión no incorporará complejidad que no aporte valor al portfolio.

## Publicación prevista

Mientras el repositorio se llame `portfolio`, la dirección pública prevista será:

`https://rubensv74.github.io/portfolio/`

Más adelante se podrá usar un dominio propio sin cambiar la base del proyecto.

## Fuente técnica

La configuración de publicación seguirá la documentación oficial vigente de Astro para GitHub Pages.
