# Portfolio profesional — Rubén Seijo

Este repositorio contiene la base del portfolio profesional de Rubén Seijo.

El objetivo no es mostrar una colección de trabajos aislados, sino explicar de forma clara cómo se analizan problemas reales, cómo se toman decisiones y cómo se convierten necesidades de negocio en soluciones digitales útiles.

## Estado actual

Estamos preparando la primera versión del portfolio.

Antes de construir la web se han definido:

- la visión del portfolio;
- el alcance de la primera versión;
- las reglas para redactar y presentar los proyectos;
- las normas de privacidad y confidencialidad.

La elección de la tecnología con la que se construirá la web queda pendiente de una decisión específica de arquitectura.

## Principio de trabajo

El portfolio debe ayudar a una persona que no conoce a Rubén a comprender, en pocos minutos, tres cosas:

1. qué tipo de problemas sabe resolver;
2. cómo piensa y trabaja;
3. qué nivel de responsabilidad puede asumir.

El diseño visual deberá estar al servicio de ese objetivo, no al revés.
